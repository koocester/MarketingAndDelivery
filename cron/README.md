# cron/

**There are no local cron jobs, LaunchAgents, PM2, or systemd timers for this system** (verified 2026-07-10 — empty crontab; LaunchAgents are only third-party app updaters).

**All scheduling lives in n8n Cloud.** See the schedule table + per-workflow triggers in [../docs/11-agents-and-cron-jobs.md](../docs/11-agents-and-cron-jobs.md) and [../docs/09-n8n-setup.md](../docs/09-n8n-setup.md).

## To add a scheduled job
Build it as an **n8n workflow** with a Schedule trigger — do **not** add local cron. Use the template in [../docs/11-agents-and-cron-jobs.md](../docs/11-agents-and-cron-jobs.md).
