Six failure modes worth remembering.

Gotcha · the SLA clocks

One field resets the SLA clock.

Last Video Stage Updated must track Video Stage only. Re-stamp it and overdue work looks new.

Part four

How to change things safely

Add carefully. Test narrowly. Document changes.

Safe move · add

Add in the UI, then tidy the views.

API-created fields appear in every view. Views themselves do not change underlying data.

Safe move · never bulk-write blind

Test one record before 200.

Bulk writes can re-stamp modified-time fields and erase the overdue picture. Confirm side effects first.

Safe move · edit, do not duplicate

Edit the original automation.

Duplicated button automations can inherit activation corruption. Change, test and document the original.

Where the truth lives

The system should explain itself.

Use the base docs, role modules and change log. Structural changes require an approved change request.

Your first week

Learn the system in one week.

  1. Read the workflow and role maps.
  2. Trace one button.
  3. Run one video end to end.
  4. Find the SLA formulas and clock field.
  5. Make, verify and document one test change.
Safe move · password management

Credentials can unlock the whole machine.

  • Use unique passwords in the shared manager.
  • Enable two-factor authentication.
  • Grant least privilege.
  • Revoke access on exit.
  • Keep secrets out of chat, docs, code and workflows.
Safe move · device management

A compromised laptop is a compromised base.

  • Inventory each device and user.
  • Enable screen lock and approved security controls.
  • Patch the system and approved apps.
  • On exit, revoke access and recover the device.
